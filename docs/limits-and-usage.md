# SuperGrok 和 Heavy 的额度、限制应该怎么看？

直接答案：把付费方案理解成“更高使用上限”，不要理解成“永久无限”。公开页面没有给出足以覆盖所有账号、地区和功能的固定次数表；真实限制可能因方案、功能、模型和系统状态变化。最可靠的做法是看自己账号当下的产品提示，并记录真实工作负载。

> 信息核验日期：2026-08-31。本页不发布未经官方页面确认的次数表。

## 为什么不写一个固定数字？

xAI 定价页对 SuperGrok 使用的是“higher rate limits”一类描述，并在方案表中区分不同层级；这不等于对所有功能都无限，也不能推出一个永远不变的次数。任何第三方给出的数字都可能只对应某个时间、地区、模型或账号实验。

## 四类限制要分开看

1. **模型限制**：不同模型可能有不同可用性或频率；
2. **功能限制**：搜索、生成图片、生成视频和复杂工具可能分别计量；
3. **时间窗口**：限制可能按小时、天、周或动态窗口恢复，实际以界面提示为准；
4. **系统状态**：高峰期、功能维护或风控会影响可用体验。

## 购买前的五个问题

- 我在哪一种模型或功能上碰到限制？
- 限制每周出现几次，实际耽误多少时间？
- 更高方案是否明确覆盖这个功能？
- 当前结算页显示的周期、币种和税费是什么？
- 如果功能或限制变化，我能否接受？

## 不应使用的表述

- “无限对话”“无限生成”；
- “永不降级”“永久稳定”；
- “任何地区都一样”；
- “买了会员就自动包含 API”；
- 未标日期、来源或账号条件的固定次数。
